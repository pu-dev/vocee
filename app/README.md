# Vocee

A small macOS topbar utility, vibed in Swift with Whisper server in python. Press F7 (or Option+Space) to start recording, press again to stop — Vocee transcribes the audio, copies the text to your clipboard, and (if enabled in Settings) pastes it straight into whatever window is active, in any app.

Now you can press F7, F8, F9, F10 or opt+space to active it - as I can't decide which to choose

## Download

```bash
git clone git@github.com:pu-dev/vocee.git
cd vocee
```

## Build

Compiles and packages the app into `Vocee.app`.

```bash
./dev/install
```

## Run

Opens the packaged app.

```bash
./dev/start
```
